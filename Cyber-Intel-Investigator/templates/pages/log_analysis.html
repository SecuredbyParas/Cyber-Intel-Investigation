Log Analysis

Upload Log File

Types of logs you can upload

1. Authentication log

SSH login records, for example /var/log/auth.log. Finds failed logins, brute force attacks and sudo commands.

Failed password for root from 185.220.101.10 port 51234 ssh2

2. Web server log

Apache or Nginx access log. Finds SQL injection, path traversal, attack tools and requests for secret files.

45.33.32.156 - - [12/Jun/2024:10:01:10 +0000] "GET /login?id=1' OR '1'='1 HTTP/1.1" 500 310 "sqlmap/1.7"

3. Firewall log

Firewall records with SRC= and DPT= fields (Linux iptables style) or a Windows pfirewall.log. Finds blocked traffic and port scans.

2024-06-12T10:00:01Z FIREWALL BLOCK TCP SRC=185.220.101.10 DST=10.0.0.1 SPT=50001 DPT=22
